# Registro de Gastos

Aplicación de consola desarrollada en **C#** para el registro y control básico de gastos.

## Funcionalidades

* Registro de gastos con descripción y monto.
* Visualización de gastos registrados.
* Cálculo del total de gastos.
* Búsqueda de gastos por descripción.
* Validación de datos ingresados.

## Ejecución

```bash
dotnet run
```

También puedes ejecutarlo desde **Visual Studio** con `F5`.
